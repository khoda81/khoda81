# Hi, I'm Mahdi Khodabandeh

**ML and systems engineer working across information theory, probabilistic interfaces, and interactive tools.**

I build software where modeling, algorithms, and systems implementation meet: exploring model distributions, visualizing uncertainty, recording market data, and making performance easier to inspect. My main languages are **Python, Rust, and TypeScript**.

## Recent work

- **[Natlas](https://github.com/khoda81/natlas)** — an interactive canvas for exploring language-model and music-transcription probability trees, with a shared Rust core for WebAssembly and Python.
- **[QBar](https://github.com/khoda81/qbar)** — framework-independent web components for uncertainty bars, nonlinear sliders, range controls, and dials, with density-aware ticks driven by quantile functions. [Playground](https://khoda81.github.io/qbar/playground)
- **[LObservatory](https://github.com/khoda81/lobservatory)** — a live Polymarket order-book and liquidity-pressure dashboard, backed by a [Rust recorder](https://github.com/khoda81/polymarket-book-recorder) with SQLite persistence and historical data access.
- **[Loghmeh](https://github.com/khoda81/loghmeh)** — an unofficial Firefox and Chrome extension for planning University of Tehran dining reservations, with a weekly calendar, budget previews, and recovery from uncertain saves. [Downloads](https://github.com/khoda81/loghmeh/releases)
- **[cargo-critdash](https://github.com/khoda81/cargo-critdash)** — a Rust CLI and live browser dashboard for comparing Criterion benchmarks, inspecting empirical effect distributions, and revisiting recorded runs.

## Research and systems

- **[natwalk](https://github.com/khoda81/natwalk)** — explore autoregressive model distributions with lazy Dijkstra search in surprisal distance and a process-isolated terminal interface. The underlying model-navigation work behind Natlas.
- **[mercy](https://github.com/khoda81/mercy)** — experimental Rust primitives for ranked-prefix arithmetic coding with exact, arbitrary-precision dyadic boundaries.
- **[bayes-2048](https://github.com/khoda81/bayes-2048)** — a Rust research benchmark comparing Bayesian value-of-computation, Thompson sampling, and UCT for allocating Monte Carlo tree-search compute in 2048.
- **[LogVec](https://github.com/khoda81/logvec)** and **[time-series-cache](https://github.com/khoda81/time-series-cache)** — sorted storage in Rust and range-query machinery for rendering workloads, respectively.
- **[Arithmetipy](https://github.com/khoda81/arithmetipy)** — streaming arithmetic coding for Python, implemented in Rust and exposed through PyO3.

Earlier work includes **[Chronickle](https://github.com/khoda81/chronickle)** ([live timeline](https://khoda81.github.io/chronickle/)), a market-and-news visualization; **[rust-2048-solver](https://github.com/khoda81/rust-2048-solver)**, a performance-focused search engine; and **[DETHCOD](https://github.com/khoda81/dethcod)**, experiments in learned lossless compression with transformers.
